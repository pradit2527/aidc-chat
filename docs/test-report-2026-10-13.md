## ขอบเขตที่ทดสอบ

**Unit (ตรรกะล้วน + route ที่ไม่ต้องใช้ Chatwoot จริง)**
- เลขตั๋ว: วันตามเวลาลาว (ขอบเขต 17:00Z), ข้ามปี, เติมศูนย์, ลำดับต่อวัน, ไม่แก้ input
- ทักทายอัตโนมัติ: ครั้งแรก / คุยต่อเนื่อง / เงียบครบ 60 นาที (ขอบเขต >=) / ปิดเคสแล้วพิมพ์มาอีก / บันทึกภายในไม่นับ / ไม่ทักซ้ำ / idle กำหนดเอง / ข้อความไม่เรียง
- ข้อความปิดเคส: ปิดบางหัวข้อ, ปิดทั้งเคสพร้อมเลขตั๋ว, ไม่มีเลขตั๋ว, label แปลก, ลำดับลาว→อังกฤษ
- แปลงข้อมูล Chatwoot: ตัวเลขรอตอบ (unread_count = 0 แต่ลูกค้าส่งล่าสุด), closed_topics มีช่องว่าง, สถานะแปลก, preview 120 ตัว/📎, ชนิดข้อความ, Bot, ไฟล์แนบชื่อภาษาลาว, payload 7 รูปแบบ
- เซสชัน: เข้ารหัส/ถอด, iv สุ่ม, token ไม่โผล่เป็นข้อความ, คุกกี้ถูกแก้ → null, หมดอายุ, เปลี่ยน secret, secret สั้น
- adminApi: CSRF (Origin/x-forwarded-host), https, parseId 9 กรณี, จำกัดล็อกอิน 10 ครั้ง/5 นาที/IP, adminRoute 401/500/403/404/502 และลบคุกกี้เมื่อ Chatwoot ตอบ 401
- i18n/หมวด/แผนก/labelName/initialOf
- `POST /api/identify`: validation, ยุบช่องว่าง, ตัดความยาว, identifier คงที่ไม่สนตัวพิมพ์, HMAC ตรง, ไม่มี token → null
- `GET /api/health`: ครบ/ไม่ครบ/Chatwoot ล่ม/บน Vercel, ไม่รั่วค่าลับ
- `POST /api/admin/login`: Origin, validation 4 แบบ, 401/502/403, คุกกี้ httpOnly + Secure บน https, ไม่เก็บรหัสผ่าน, 429
- ticketMap/fetchConversationsSince: แบ่งหน้า หยุดที่ต้นวัน เพดาน 12 หน้า cache 20 วินาที
- ทะเบียน Ticket เมื่อไม่มี DATABASE_URL: ทุกฟังก์ชันเป็น no-op ปลอดภัย

**End-to-end (เซิร์ฟเวอร์จริงบนเครื่องพัฒนา + Chatwoot จำลอง + ฐาน Neon `aidc_chat_test`)**

- กรองป้าย, ป้าย/สถานะผิดถูกละเว้น, จำนวนงานต่อป้าย (นับเฉพาะหัวข้อที่ยังไม่ปิด)
